# Year 3-4 Bounded Execution Baseline

This document records the repository-level Year 3-4 baseline. It does not claim
that external infrastructure is deployed or institutionally certified.

## Year 3

- Blockchain events, mempool risk, wallet graph, cross-chain flow, DeFi health,
  contract risk, signed audit artifacts, and hybrid financial fusion are explicit.
- Protocol research is sandboxed and never receives execution authority.
- DeFi failure scenarios are deterministic simulation inputs.

## Year 4

- Event sourcing now has Redis Streams durability, external bus contracts, CQRS projections, and snapshot replay.
- Redis Streams replay export writes immutable JSONL datasets with manifest hash verification.
- World modeling includes causal macro state, capital flow, and probabilistic regimes.
- Portfolio cognition exposes stress loss, drawdown probability, and hedge targets.
- Governance V2 blocks execution on unsafe runtime, uncertainty, portfolio, blockchain,
  or unsigned-artifact states.
- Rust has a protocol-gated pilot crate. Python remains the active runtime.
- Multi-agent validation, black-swan simulation, latency budgets, smart routing, and
  replay-native research evaluation are bounded local foundations.

## Deployment Gaps

- Validate Redis Streams high availability, retention, backup, and recovery drills.
- Move to NATS JetStream or Kafka only when measured scale requires it.
- Use Ed25519 operator signing for production decisions; HMAC remains a local
  compatibility fallback only.
- Wire the Rust pilot into live streaming and execution processes.
- Capture production-grade datasets and validate replay determinism during shadow operation.
